​📥 Installation & Usage
​To install and run TB-guard on your Termux or Linux terminal, follow these steps:

1.Update your packages:

pkg update && pkg upgrade -y


2.Install dependencies (Git and Python):

pkg install git python -y



3.Clone the repository

git clone https://github.com/tbg-sys/TB-guard.git


4.Navigate to the folder

cd TB-guard


5.Run the program

python tbguard.py
